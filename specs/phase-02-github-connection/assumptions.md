# Phase 2: Assumptions

An assumption is **not** a decision. Each can be challenged. Sources: `repository observation` (verified by reading the repo), `owner statement`, `handoff` (phase prompt), `inference` (author's reasoning). Status is **Open** (still an assumption), **Resolved** (settled by an owner decision, kept for the record) or **Updated**. Items added in revision 1 carry `[REV1]`; items added in revision 2 carry `[REV2]`.
